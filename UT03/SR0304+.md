# Recursión y autoridad: dos características distintas

**Recursiva o iterativa describe la consulta. Autoritativa o no autoritativa describe la respuesta.** Una característica no determina automáticamente la otra.

| Concepto | Qué indica |
|---|---|
| Consulta recursiva | El cliente pide al servidor una respuesta final o un error. |
| Consulta iterativa | El servidor devuelve lo que conoce: respuesta, error o referencia a otros servidores. |
| Respuesta autoritativa | El servidor tiene autoridad para la zona correspondiente. Puede ser primario o secundario. |
| Respuesta no autoritativa | El servidor responde sin ser autoridad para ese nombre. Puede usar información de caché o recién obtenida. |

### Respuesta autoritativa: datos de la zona

Supongamos que `ns1.aula.test.` tiene autoridad para `aula.test.`. Si responde sobre un registro de esa zona, su respuesta puede ser autoritativa aunque la consulta recibida sea iterativa. También puede responder de forma autoritativa que el nombre no existe.

Una respuesta autoritativa no implica siempre que ya se haya obtenido toda la información necesaria para la aplicación. Por ejemplo, un CNAME puede apuntar a un nombre de otra zona que todavía deba resolverse.

La autoridad tampoco es una garantía criptográfica. DNSSEC es un mecanismo diferente.

### Respuesta no autoritativa: información obtenida de otros DNS

Un resolvedor consulta al servidor autoritativo de `example.com`, obtiene una respuesta y la devuelve a su cliente. La respuesta del resolvedor normalmente será no autoritativa para ese nombre, aunque acabe de obtenerla y sea válida.

### Ejemplo del recorrido habitual

1. El cliente solicita recursión a su DNS configurado.
2. Si necesita buscar en Internet, el resolvedor puede hacer consultas iterativas a otros DNS.
3. Los servidores de la jerarquía devuelven referencias o respuestas.
4. El servidor autoritativo responde con los datos de su zona.
5. El resolvedor devuelve el resultado al cliente.

Que una consulta sea iterativa no obliga a devolver una referencia. Puede recibir directamente la respuesta final.

### Resumen clave:

- **No autoritativa** no significa incorrecta.
- **NXDOMAIN** indica que el nombre no existe según la respuesta DNS.
- **Tiempo de espera agotado** indica que no llegó una respuesta a tiempo. No demuestra que el nombre no exista.

Referencia: [RFC 1034, consultas y funcionamiento de los servidores](https://www.rfc-editor.org/rfc/rfc1034.html).
