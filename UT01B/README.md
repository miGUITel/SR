# UT01B. Conexión de red en VirtualBox

![Red de servidores y equipos conectados](./img/cabecera_ut01b.png)

En esta unidad prepararás máquinas virtuales reutilizables, configurarás sus interfaces de red y comprobarás la comunicación entre ellas.

La unidad se organiza en tres sesiones. Abre primero el documento conductor de cada sesión y consulta los anexos solo cuando los necesites.

Resultado esperado: tres máquinas madre comprobadas y clones de trabajo con direcciones MAC distintas.

Documento conductor:

## Idea común de trabajo

1. Preparar las máquinas y los adaptadores.
2. Configurar únicamente los parámetros necesarios.
3. Comprobar interfaces, direcciones y rutas.
4. Probar la comunicación y el servicio solicitado.
5. Localizar y corregir los fallos.
6. Conservar las evidencias que expliquen el resultado.

Los enunciados evaluables y las instrucciones de entrega se publican en el Aula Virtual, no en este repositorio.
